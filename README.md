# LIFE OS — Content Agent

MVP v0.1 do sistema editorial do LIFE OS.

## Objetivo
Transformar insights reais em conteúdo profissional com fluxo de aprovação humana:

INSIGHT → PAUTA → DRAFT → AGUARDANDO_APROVACAO → APROVADO → AGENDADO → PUBLICADO → ANALISADO

## MVP atual
- Dashboard responsivo
- Inbox de insights
- Conteúdos e status
- Aprovação humana
- Calendário editorial
- Métricas preparadas para integração
- Regras editoriais v1
- Post #001 cadastrado como aprovado
- Persistência local no navegador (localStorage)
- Sem dependências e sem custo de API

## Próximas etapas
1. Conectar Supabase para persistência real.
2. Autenticação privada.
3. Armazenamento de mídia.
4. Conectar a API oficial do Instagram.
5. Agendamento/publicação após aprovação.
6. Retorno de métricas para o agente.

> Nenhum conteúdo deve ser publicado automaticamente sem aprovação humana durante esta fase.
